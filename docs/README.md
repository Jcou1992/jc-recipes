# docs/

Human-authored documentation (not generated). Safe to reorganize — referenced only by markdown links.

- `plans/` — feature/sprint plans and PRDs.
- `specs/` — design specs (cooking companion, photos, macros, onboarding, motion system).
- `ideation/` — routing/user-flow audits and diagrams.
- `design-history/` — the design-contest summary, learnings, and the design records that shipped.
- `data-model.md`, `runbook-seed-users.md` — schema docs and operational runbooks.

For "what calls what" architecture questions, prefer `graphify-out/GRAPH_REPORT.md` over reading raw files.
