# Impeccable Design Context

## Design Context

### Users
**Primary:** JC only. Phone propped against the kitchen backsplash while cooking. Hands possibly dirty, kitchen lighting harsh, pace fast. No audience — this is a working tool. The job: find the recipe, scale it, cook it, get out.

**Context footnote:** JC runs a real restaurant called Sakai. He's proud of it. This app may or may not carry the Sakai name — that's undecided — but it should be *worthy* of that name if it does.

### Brand Personality
**Three words:** precise, proud, functional

**Metaphor:** Restaurant mise en place. Everything visible, organized, and within reach before service starts. No decorative clutter. Every element earns its place by doing something useful. The beauty comes from order and readiness, not from ornamentation.

**Emotional goal:** Confidence and calm. When you open this app mid-cook, it should feel like picking up a good knife — weight in your hand, edge where you expect it. No hunting, no friction.

### Aesthetic Direction
**Current palette:** Terracotta (#D4703F) + Gold (#EDD18E) + Ink/Bone neutrals. Dark mode default. **Keep and polish.**

**Typography:** Cormorant Garamond (body), Noto Serif JP (display/titles), Barlow Condensed (labels/UI chrome). **Keep and tighten the hierarchy.**

**Theme:** Dark default is correct. Kitchen context, nighttime cooking sessions, phone screen brightness down. Light doesn't serve this use case.

**The Sakai question:** Design every screen as if it *could* carry the Sakai name without embarrassment. Restaurant-grade, not home-cook-app grade. If the name never appears, the quality standard still applies.

**Anti-references:**
- Not a consumer food app (AllRecipes, Yummly) — no stock photos, no CTAs, no upsells
- Not a lifestyle cooking blog — no soft watercolor, no "rustic" decorative elements
- Not a notes app with a recipe plugin — this is a purpose-built cooking tool

### Design Principles
1. **Every pixel earns its place.** No decorative element without functional justification. Mise en place: nothing on the pass that isn't needed for service.
2. **Legibility under pressure.** Kitchen lighting is hard. Hands are wet. Text must be unambiguous at a glance. Hierarchy must be obvious without requiring attention.
3. **Polish, don't rebuild.** The terracotta/gold/serif direction is right. Elevation comes from refinement — tighter spacing, crisper type sizing, better rhythm — not from reinvention.
4. **Worthy of the name.** Restaurant-grade finish. If Sakai ever appears in the UI, it should belong there. Every screen should pass that bar whether the name is present or not.
5. **Speed over everything.** Optimistic UI, instant feedback, no waiting. A chef does not wait for confirmation dialogs.
